1Q : What is the difference between Internal tables and External tables? Write a Hive query for creating a hive internal and external tables?
Ans : Internal tables :
      1. We do not mention the location while we are creating an internal table.
      2. Internal table is fully managed by Hive which means hive manages the meta data, schema and actual data of the table.
      3. When we drop an internal table the meta data and the actual data of the table will be deleted.
      4. The performance of the internal table is not impacted by the external storage systems.
      Hive internal table creation :
      create table Employees (
      id int, name string, age int, salary int )
      row format delimited
      fields terminated by ','
      stored as 'textfile";

      External tables :
      1. We will mention the location while we are creating an external table.
      2. External table is not fully managed by hive which means hive manages the meta data and schema of the table.
      3. When we drop an external table the meta data of the table will be deleted. The actual data will be stored in HDFS or in the external location where we mentioned.
      4. The performance of the external table is impacted by the external storage systems.
      Hive external table creation :
      create table Employees_Ext (
      id int, name string, age int, salary int )
      row format delimited
      fields terminated by ','
      stored as 'textfile'
      location 'user/Hadoop/data/Employees_Ext'

2Q : What is the difference between Partitioning and Bucketing in hive? Give example for both?
Ans : Partitioning and Bucketing are two optimization techniques in hive to improve the query performance by reducing the amount of data scanned.
      Partitioning :
      Partitioning divides a table into parts based on the values of a partition column.
      Each partition stored as a separate directory in HDFS.
      Syntax :
      create table table_name (
      column_name data_type,
      column_name data_type )
      partitioned by (column_name data_type);
      Ex :
      create table Students (
      name string,
      marks int )
      partitioned by (branch string);

      Bucketing :
      Bucketing divides data within a table into a fixed number of files based on the hash of a bucketing column.
      Each bucket is stored as a file with in the table's directory or the partition's directory.
      Syntax :
      create table table_name (
      column_name data_type,
      column_name data_type )
      clustered by (column_name) into n buckets;
      Ex :
      create table Sales (
      Product int,
      amount int )
      clustered by (Product) into 4 buckets;

3Q : What is the difference among truncate, delete and drop commands? Write a syntax and give me an example code for truncate, delete and drop commands?
Ans : Truncate :
      It will delete all the rows from the table.
      Syntax : truncate table table_name
      Ex : truncate table Customers;

      Delete :
      It will delete one or more rows from the table based on the condition.
      Syntax : delete from table_name where condition
      Ex : delete from Customers where customer_name='John'; 

      Drop :
      It will delete the entire table from the database.
      Syntax : drop table table_name;
      Ex : drop table Customers;
====================================================================================================================================================================
4Q : What is the difference between update and alter commands in SQL? Write a syntax and give me an example code for both update and alter commands?
Ans : Update :
      It is used to add or update the column values of a table.
      Syntax : update table_name where condition
      Ex : update customers set country='India' where customer_id=1;

      Alter :
      It is used to add a new column or delete an existing column from a table.
      Syntax : alter table table_name
               add column_name datatype
      Ex : alter table customers
           add Email varchar(255);

5Q : Which command is used to delete a row and a column from a table in SQL? Write a syntax and give me an example code for both?
Ans : 1) We use delete command to delete a row from the table.
         Syntax : delete from table_name
                  where condition;
         Ex : delete from customers
              where age = 25;
      2) We use drop command to delete a column from the table.
         Syntax : alter table table_name
                  drop column column_name;
         Ex : alter table customers
              drop column country;

Ans : When any column values are fixed and no need to update every time, then we use default constraint.

7Q : What are SQL databases and NoSQL databases? Give me some examples?
Ans : Both SQL and NoSQL databases are used to store and manage the data.
      SQL database :
      These are relational databases used to store the data in tables with rows and columns.
      These are mainly known for their ACID properties.
      Ex : MySQL, PostgreSQL, Oracle Database, Microsoft SQL Server and SQLite.

      NoSQL database:
      These are non-relational databases designed to handle unstructured and semi-structured data.
      These are more flexible than SQL databases and can scale horizontally.
      Ex :
      Key-Value stores : Redis, Amazon Dynamo DB
      Document stores : MongoDB, CouchDB
      Column-Family stores : Apache Cassandra, HBase
      Graph databases : Neo4j, Amazon Neptune
