7Q : What is rownumber, rank and denserank? Give their syntax and write a code for finding them?

Ans : rownumber, rank and denserank are the window functions used to assign a value to each row within a window partition.

      rownumber : It is used to assign a unique number to each row within a window partition starting from 1
      Syntax : val windowSpec = Window.partitionBy("Branch").orderBy(desc("Marks"))
               val rowNumberDF = df.withColumn("RowNumber",row_number().over(windowSpec))

      rank : It assigns a rank to each row within a window partition starting from 1 but if there are any ties, rank assign
             the same rank to all tied rows and the next rank skips the number of tied rows
      Syntax : Val rankDF = df.withColumn("Rank", rank().over(windowSpec))

      dense_rank : It is similar to rank but doesnot skip any ranks when there are any ties.
                   if there are any ties dense_rank assigns the same rank to all tied rows but the next rank is consecutive.
                   (or)
                   In Spark dense rank is a window function that assigns a rank to each row within a window partition, with no gaps
                   in the ranking values.
      Syntax : val denserankDF = df.withColumn("DenseRank", dense_rank().over(windowSpec))

      Ex : Refer WindowFunctions package in spark_codes_ak for complete program

12Q : Can i create a single column data frame using createDataFrame? If not why?

Ans : No, we can't achieve this with createDataFrame() method.
      In Spark Scala, the createDataFrame method fails for a single column when you pass a collection of primitive types (like Seq[String] or Seq[Int])
      because the method expects data structured as a product type (a Scala Product like a Tuple or a Case Class) or explicit Spark Row objects.
      val data = Seq(1, 2, 3)
      val df = spark.createDataFrame(data).toDF()
      df.show(false)
      
      // It wont get compiled. It will throw an error

      we can create a data frame like below,
      val df = data.toDF()
      df.show(false)

15Q : When to use = , == and === usage in Spark Scala Data frames?

Ans : 
We use = for variable assignment in Scala.
We use == for standard Scala object reference or value comparison.
We use === for Spark SQL column-level equality expressions.

1) = : Assignment
Usage :
Used to assign a value, expression, or DataFrame to a variable or to name parameters in a function.
Ex :
var a = 4
val df = spark.read.csv("file1.csv")

2) == : Scala Equality
Usage :
Used in standard Scala code to compare two objects or values for equality (checking reference equality or value equality depending on the data type),
returning a standard Scala Boolean (true or false).
Do not use this inside Spark DataFrame transformations like .filter() or .select() when comparing columns, as it does not build a Spark column expression.
Ex :
val isEqual = (5 == 5)
returns true

3) === : Spark Column Equality
Usage :
Used to construct a Spark Column expression for element-wise comparisons inside DataFrame transformations (such as .filter(), .where(), or .join()).
It translates to an internal Spark SQL EqualTo expression.
Ex :
val df3 = df1.filter(col("Marks") === 35)
val df4 = df1.join(df2, df1("ID") === df2("ID"), "Inner")

Refer Equal_DoubleEqual_TrippleEqual package in spark_codes_ak for complete program

16Q : Read and write CSV, Parquet, Avro, ORC, Text, JSON, XML file formats to spark Data Frame?
Ans :
1) CSV file format :
   // Writing a data frame to csv file
   df.write.option("header","true").option("InferSchema","true").csv("C:\\FileFormats\\CSV\\students.csv")
   
   // Reading a csv file to spark data frame
   val studentsCSVDF = spark.read.option("header","true").option("InferSchema","true").csv("C:\\FileFormats\\CSV\\students.csv")

2) Parquet file format :
   // Writing a data frame to parquet file
   df.write.parquet("C:\\FileFormats\\Parquet\\students.parquet")

   // Reading a parquet file to spark data frame
   val studentsParquetDF = spark.read.parquet("C:\\FileFormats\\Parquet\\students.parquet")

3) Avro file format :

   Add this maven dependency to pom.xml file :

   <dependency>
            <groupId>com.databricks</groupId>
            <artifactId>spark-avro_2.11</artifactId>
            <version>4.0.0</version>
        </dependency>   

   Then only Avro read and write operations will work.
   
   // Writing a data frame to avro file
   df.write.format("com.databricks.spark.avro").save("C:\\FileFormats\\Avro\\students.avro")

   // Reading an avro file to spark data frame
   val studentsAvroDF = spark.read.format("com.databricks.spark.avro").load("C:\\FileFormats\\Avro\\students.avro")

4) ORC file format :
   
   add this maven dependency to pom.xml file :
   
   <dependency>
            <groupId>org.apache.spark</groupId>
            <artifactId>spark-hive_2.11</artifactId>
            <version>2.3.1</version> <!-- Match your Spark version -->
            <!-- Remove <scope>provided</scope> if running locally from your IDE -->
        </dependency>
   
   then enable hive support with the below :

   val spark: SparkSession = SparkSession.builder()
      .master("local[1]").appName("Reading and writing all file formats")
      .enableHiveSupport()
      .getOrCreate()

   // Writing a data frame to orc file
   df.write.format("orc").save("C:\\FileFormats\\ORC\\students.orc")

   // Reading an orc file to spark data frame
   val studentsORCDF = spark.read.format("orc").load("C:\\FileFormats\\ORC\\students.orc")

5) Text file format :
   // Writing a data frame to text file
   df.write.option("header", "true").option("inferSchema", "true").option("delimiter", ",").csv("C:\\FileFormats\\Text\\students.txt")

   // reading a text file to spark data frame
   val studentsTextDF = spark.read.option("header", "true").option("inferSchema", "true").option("delimiter", ",").csv("C:\\FileFormats\\Text\\students.txt")

6) JSON file format
   // writing a data frame to a json file
   // df.write.json("C:\\FileFormats\\JSON\\students.json")

   // reading a json file to spark data frame
   val studentsJSONDF = spark.read.json("C:\\FileFormats\\JSON\\students.json")

7) XML file format
   
   add this maven dependency to pom.xml file :

   <dependency>
            <groupId>com.databricks</groupId>
            <artifactId>spark-xml_2.11</artifactId>
            <version>0.6.0</version>
        </dependency>

   Then only xml read and write operations will work.

   // writing a data frame to a xml file
   df.write.format("com.databricks.spark.xml").option("rootTag","people").option("rowTag","ppl").save("C:\\FileFormats\\XML\\students.xml")

   // reading a xml file to spark data frame
   val studentsXMLDF = spark.read.format("com.databricks.spark.xml").option("rowTag", "ppl").load("C:\\FileFormats\\XML\\students.xml")
