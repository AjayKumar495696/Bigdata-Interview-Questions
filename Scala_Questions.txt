1Q  : What is Scala?
Ans :  -> Scala stands for Scalable language.
       -> It is a general-purpose, high level, pure object oriented programming language.
       -> It provides the support to the functional programming approach.
       -> Scala programs can convert byte codes and can run on the JVM (Java Virtual Machine).
       -> It is highly influenced by Java.

9Q : Difference between Val and Var keywords in Scala?
Ans : Val and Var are used to define variables.
      Val :
      Val is a immutable variable. Once a variable is assigned to Val, it can't be reassigned.
      val x = 20
      x = 10 //It won't get compiled

      Var :
      Var is mutable variable. We can reassign a value to it, once we created.
      var x = 30
      x = 20
      println(x)  //20

3Q : What is the difference between map and flatMap?
Ans : Map and flatMap are higher order functions in Scala. They used to transforms the collections.
      Map :
      Map is used to apply a function to each element of a collection and returns a new collection where each element of the collection is the result of applying function.

      flatMap :
      flatMap is also used to apply a function to each element of a collection and returns a new collection but here it flatten the result into a single collection.
====================================================================================================================================================================
4Q : Write a program for map and flatmap in Scala?
Ans : Map :
      Ex : Val myList1 = List(1,2,3,4)
           val doubledList = myList1.map(x=>x*2)
           println(doubledList)
           O/P : List(2,4,6,8)

      flatMap :
      Ex : val myList2 = List(1,2,3,4)
           val flatMapList = myList2.flatMap(x=>List(x,x*2))
           println(flatMapList)
           O/P : List(1,2,2,4,3,6,4,8)

5Q : What is the use of yield keyword in Scala?
Ans : We use yield keyword to apply a function to each element and returns a new collection with transformed elements.
====================================================================================================================================================================
6Q : Write a program for yield keyword in Scala?
      yield keyword :
      Ex : val myList = List(1,2,3,4)
           val doubledList = for(i <- myList) yield i*2
           println(doubledList)
           O/P : List(2,4,6,8)

7Q : What is the difference between list and array?
Ans : List and Array are data structures in Scala and used to store the sequence of elements.
      List :
      List is an immutable collection. Once we create any list, we can't change the values in it.
      When we update the list every time, a new list will be created.

      Array :
      Array is a mutable collection. Once we create any array, we can change the values in it.
====================================================================================================================================================================
8Q : Write a program for list and array in Scala?
Ans : List :
      Ex : var myList = List(1,2,3,4)
           myList(0) = 5      
           println(myList)      // it won't get compiled, it will throw an error

      Array :
      Ex : var myArray = Array(1,2,3,4)
           myArray(0) = 6
           for (i <- myArray) {
               println(i)
             }
           O/P : 6 2 3 4

16Q : What are the different types of inheritance available in Scala? Explain me? Write a code for each inheritance with example?
Ans : Single inheritance, Multilevel inheritance, Hirarchial inheritance, Multiple inheritance and Hybrid inheritance.
      a) Single inheritance :
         A ---> B
      b) Multilevel inheritance :
         A ---> B ---> C
      c) Hirarchial inheritance :
              ----> B
              |
         A ---|---> C
              |
              ----> D
      d) Multiple inheritance
             A       B
             |       |
             |       |
             ---------
                 |
                 C
      e) Hybrid inheritance
                  A
                 / \
                /   \
               B     C
               \     /
                \   /
                  D

10Q : What are traits in Scala?
Ans : Trait is similar to interface in Java, but with more capabilities. Traits are used to define a set of fields
      and methods that can be mixed into classes. They provide a way to share interfaces and fields between classes
      without using inheritance.
      
Ans : -> Trait is a concept which can extend the functionality of a class using a set of methods.
      -> A trait can define abstract methods and fields, just like an interface, but it can also define concrete methods
	 and fields, as well as implement methods.

17Q : What is class and object in Scala?
Ans : Classes and Objects are basic concepts of Object Oriented Programming.
      Class :
      Class is a user-defined blueprint or prototype from which objects are created.
      A class combines the fields and methods into a single unit.
      Object :
      It is a basic unit of Object oriented programming and represents the real-life entities. An object consists of
      State, Behavior and Identity.

20Q : Why Scala is Popular among other programming languages?
Ans : 1) Easy to Start :
            -> Scala is high level language so it is closer to other popular programming languages like Java, C, C++.
            -> Thus it becomes very easy to learn Scala for anyone.
            -> For Java Programmers, Scala is more easy to learn.
      2) Contains best features :
            -> Scala contains the features of different languages like C, C++, Java etc.
            -> Which makes it more useful, scalable and productive.
      3) Close integration with Java :
            -> The source code of the Scala is designed in such a way that its compiler can interpret the Java classes.
            -> Also, its compiler can utilize the frameworks, Java Libraries, and tools etc.
            -> After compilation, Scala programs can run on JVM.
      4) Web - Based & Desktop Application Development :
            -> For the web applications it provides the support by compiling to JavaScript.
            -> Similarly for desktop applications, it can be compiled to JVM bytecode.
      5) Used by Big Companies :
            -> Most of the popular companies like Apple, Twitter, Walmart, Google etc. move their most of codes to Scala from some other languages.
            -> Reason being it is highly scalable and can be used in backend operations.
